#  Data Visualization Project

##  Project Overview

This project is a **Data Visualization project created using Google Colab**. It uses Python and different data visualization libraries to analyze datasets and present useful insights through charts and graphs.

## 🛠️ Technologies & Libraries Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly

## 📈 Visualizations

The project includes different types of visualizations such as:

* Bar Charts
* Line Charts
* Pie Charts
* Histograms
* Box Plots
* Scatter Plots
* Count Plots

##  Objective

The main objective of this project is to understand data, perform basic analysis, and represent information visually using Python visualization libraries.

##  How to Use

1. Download or clone this repository.
2. Open the `.ipynb` file using **Google Colab** or **Jupyter Notebook**.
3. Run the cells step by step.
4. View the generated charts and analysis.

## Files

* `Data_Visualization.ipynb` – Main Google Colab notebook containing the Python code, visualizations, and analysis.
